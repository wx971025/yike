## 一、项目简介

**忆刻（YiKe）** 是一款面向长期学习者的 **智能复习系统**。以 **艾宾浩斯遗忘曲线** 为核心调度引擎，覆盖 **记忆卡片、单词、易混词** 三类学习内容，支持 **Web 在线版** 与 **Windows / macOS 桌面版**，并内置 **AI 助手** 协同管理学习计划。

本项目解决的核心痛点是：学习者「记了却容易忘、复习计划难坚持、工具之间数据割裂」。许多笔记类、背单词类 App 只解决「录入」，却缺少科学的 **到期提醒、逾期追踪、双轨复习策略** 与 **跨设备进度同步**。忆刻将「记录 → 计划 → 今日复习 → 日历预览 → 数据备份」串成闭环，让复习变成可执行、可坚持的日常习惯。

### 核心功能一览

| 功能模块 | 描述 | 技术亮点 |
|----------|------|----------|
| **今日复习** | 聚合待复习卡片、单词（拼写/认知双轨）、易混词，支持分组筛选与进度追踪 | 到期必现 · 逾期高亮 · 批次锁定 |
| **艾宾浩斯调度** | 7 轮间隔复习（1→3→7→15→30→60→180 天），完成即标记掌握 | 分组自治 · 按学习日重算 schedule |
| **连续巩固** | 7 / 15 / 30 天每日复习模式，适合考前冲刺 | 与间隔复习分组级切换 |
| **单词复习** | 释义→拼写 / 认知双模式，乱序固定种子，打字机音效与快捷键 | 沉浸式 UI · 偷看答案排队尾再练 |
| **易混词对** | 成对管理易混淆词汇，专项对比复习 | 拼错时 AI 辅助生成易混词建议 |
| **复习日历** | 月历预览未来复习安排，按分组查看 | 北京时间日切 · 可视化路径 |
| **AI 助手** | 自然语言管理分组、卡片、单词、计划；支持 `@分组` 与 Agent Skill | OpenAI 兼容 API · 可配置模型 |
| **数据同步** | JSON 导入导出；Web 同步码 + 桌面 push/pull；含配置与复习进度 | 全量 replace · 跨端一致 |
| **多端交付** | Web + Windows 安装包 + macOS dmg，应用内更新与国内镜像 | PyWebview · Docker · CI 发版 |

## 二、商业价值与市场机会

### 2.1 市场痛点

- **背了忘、忘了再背**：缺乏科学间隔，复习集中在考前，长期 retention 差。
- **工具碎片化**：单词 App、笔记 App、日历提醒各自独立，学习数据无法统一调度。
- **坚持成本高**：没有「今日待办」式强提醒，逾期内容容易被静默跳过。
- **AI 仅会聊天**：通用 ChatGPT 能答疑，但难以 **持久跟踪** 每个知识点的复习轮次与掌握状态。

### 2.2 目标市场规模

| 细分市场 | 估算规模 | 切入理由 |
|----------|----------|----------|
| K12 / 考研 / 考证 | 数千亿元级（学习工具大盘） | 艾宾浩斯方法论认知度高，复习刚需 |
| 语言学习（单词） | 数百亿元/年 | 拼写+认知双轨，区别于纯背单词 |
| 职业考证 / 碎片化学习 | 数百亿元/年 | 记忆卡片 + 自定义分组，适配多场景 |
| 个人知识管理（PKM） | 快速增长 | 与 Notion/Anki 用户群重叠，强调「轻量+AI」 |

### 2.3 核心竞争优势

- **复习优先，而非录入优先**：「今日复习」为首页，到期内容必现，逾期持续提醒。
- **分组自治记忆策略**：同一用户可对不同科目选用艾宾浩斯或连续巩固，互不干扰。
- **三端一致 + 离线桌面**：Web 云端 + Windows/macOS 本地 SQLite，同步码一键迁移。
- **AI 嵌入工作流**：不是独立聊天框，而是直接操作分组、卡片、单词与计划。
- **开源可部署**：Docker 一键部署，适合学校/机构私有化试点。

## 三、商业模式

忆刻采用 **免费基础版 + 订阅增值 + B 端定制** 的路径，先以 C 端个人用户验证留存，再拓展教育场景。

### 3.1 C 端：Freemium + 订阅

| 版本 | 免费版 | Pro 版（¥19/月） | 旗舰版（¥49/月） |
|------|--------|------------------|------------------|
| 卡片 / 单词数量 | 500 条上限 | 不限 | 不限 |
| 分组数 | 5 个 | 不限 | 不限 |
| AI 助手调用 | 20 次/天 | 200 次/天 | 不限 |
| 数据同步 | 手动导出 | 云端自动同步 | 多端 + 历史版本 |
| 桌面版 | 基础功能 | 全功能 | 全功能 + 优先更新 |

### 3.2 B 端：行业定制

- **培训机构版**（¥8,000–30,000 元/年）：白标部署、学员管理、复习报表导出。
- **学校/班级版**（项目制）：教师布置词表/知识点，学生按艾宾浩斯节奏复习，后台看完成率。
- **企业内训版**：岗位知识卡片 + 复习合规追踪。

### 3.3 其他变现方向

- **API / 插件**：向第三方 LMS 提供复习调度 API。
- **优质词库/模板市场**：官方与创作者分成。
- **与 AI 厂商合作**：内置模型推荐与 Key 分销（合规前提下）。

## 五、技术实现亮点

| 维度 | 说明 |
|------|------|
| **前端** | React 18 + TypeScript + Vite + Tailwind；单词复习沉浸式 UI、侧栏图标模式 |
| **后端** | Python 3.11 + FastAPI + SQLAlchemy；JWT 鉴权、复习调度服务、数据迁移体系 |
| **数据** | SQLite（Web Docker Volume / 桌面本地）；export v2 含 settings、批次、复习进度 |
| **AI** | OpenAI 兼容接口；Agent Skill 可扩展；`@分组` 精确操作范围 |
| **桌面** | PyWebview + PyInstaller + Inno Setup（Win）/ dmg（macOS）；托盘驻留、应用内更新 |
| **部署** | Docker Compose + Nginx；GitHub Actions 打 tag 自动构建 Release；国内更新镜像 |
| **当前版本** | v1.1.22（2026-07-24），Web 已部署，三端可演示 |

### 架构示意

```
浏览器 / 桌面 WebView (React)
        ↓
   Nginx / 本地 API
        ↓
   FastAPI（复习引擎 · AI · 数据同步）
        ↓
      SQLite
```
